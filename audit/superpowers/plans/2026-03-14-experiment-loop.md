# Experiment Loop Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn every wave 1 run into a scored experiment with keep/discard selection pressure, enabling autonomous overnight prompt optimization (autoresearch model).

**Architecture:** Three layers: (1) `experiment.py` computes `audit_score` from existing synthesis/metrics data and manages `experiments.tsv`; (2) `run_audit.py` gains `--experiment` mode that scores after each wave and applies keep/discard; (3) `run_experiment.py` is the autonomous "LOOP FOREVER" engine that proposes prompt changes, runs experiments, and iterates. Layer 3 is designed but NOT built in this plan — it requires a meta-researcher agent prompt which should be iterated on after Layer 1+2 prove the scoring works.

**Tech Stack:** Python 3.13, existing orchestrator modules, TSV for experiment log (matches autoresearch `results.tsv` format)

- [ ] **Step 1: Create experiment.py with compute_audit_score()**

```python
"""Experiment tracking for autoresearch-style prompt optimization.

Each wave 1 run is an experiment. The audit_score is a composite metric
computed from existing synthesis and metrics data. Higher is better.

Modeled after karpathy/autoresearch: fixed-budget experiments, single
metric, keep/discard selection pressure, persistent TSV log.
"""

import csv
import json
import subprocess
from dataclasses import dataclass, asdict
from datetime import datetime, timezone
from pathlib import Path

from .config import ARTIFACTS_DIR, RESULTS_DIR


@dataclass
class ExperimentResult:
    """One row in experiments.tsv."""
    run_id: str
    commit: str          # git short hash at time of run
    audit_score: float   # composite metric (higher = better)
    regression: str      # "2/4" format
    findings: int        # confirmed findings count
    tool_pct: int        # % mandatory tools actually run (0-100)
    vectors: int         # total ruled-out vectors
    forge_tests: int     # hypotheses with Forge test evidence
    wall_time_s: int     # wall clock seconds
    status: str          # "keep" | "discard" | "crash"
    description: str     # what changed in this experiment


# --- Scoring ---

# Weights encode priorities: real findings > regression > tools > thoroughness
SCORE_WEIGHTS = {
    "regression":  25.0,   # 0-4 known bugs → 0-100 (25 pts each)
    "findings":    40.0,   # each confirmed finding = 40 pts (capped at 200)
    "tool_pct":     0.15,  # tool compliance % → 0-15 pts
    "vectors":      0.10,  # vectors/100 → 0-10 pts (capped)
    "forge_tests":  0.10,  # forge_test_pct → 0-10 pts (capped)
}


def compute_audit_score(wave_number: int = 1) -> ExperimentResult:
    """Compute audit_score from existing synthesis + metrics files.

    Reads:
      - wave{N}-synthesis.json (findings, ruled_out, tool warnings, regression)
      - wave{N}-metrics.json (turns, duration, agent count)
      - wave{N}-safety.jsonl (safety events)
      - manifest.json (run_id)

    All these files are already generated by synthesizer.py and run_audit.py.
    This function does NOT run any agents — it scores what already exists.
    """
    synthesis_path = ARTIFACTS_DIR / f"wave{wave_number}-synthesis.json"
    metrics_path = RESULTS_DIR / f"wave{wave_number}-metrics.json"
    manifest_path = ARTIFACTS_DIR / "manifest.json"

    if not synthesis_path.exists():
        raise FileNotFoundError(f"No synthesis found: {synthesis_path}")

    synthesis = json.loads(synthesis_path.read_text())
    metrics = json.loads(metrics_path.read_text()) if metrics_path.exists() else {}
    manifest = json.loads(manifest_path.read_text()) if manifest_path.exists() else {}

    # --- Extract raw values ---

    # Findings
    confirmed_findings = len(synthesis.get("findings", []))

    # Regression (from run_audit.py's regression check output in synthesis)
    # The regression result is logged to stdout but not in synthesis.json,
    # so we re-run the check here against cumulative sidecars.
    regression_found, regression_total = _check_regression(wave_number)

    # Tool compliance (count agents that ran mandatory tools vs total)
    tool_warnings = synthesis.get("tool_coverage_warnings", [])
    agent_count = metrics.get("config", {}).get("agents", 6)
    tool_pct = _compute_tool_compliance(tool_warnings, agent_count)

    # Vectors ruled out
    vectors_ruled_out = synthesis.get("ruled_out_count", 0)

    # Forge test rate (count ruled-out vectors with test_file != null/N/A)
    forge_tests = _count_forge_tests(wave_number)

    # Wall time
    agents_data = metrics.get("agents", [])
    wall_time_s = max((a.get("duration_ms", 0) for a in agents_data), default=0) // 1000

    # --- Compute composite score ---
    score = 0.0
    score += regression_found * SCORE_WEIGHTS["regression"]      # 25 pts per regression bug
    score += min(confirmed_findings * SCORE_WEIGHTS["findings"], 200)  # cap at 200
    score += tool_pct * SCORE_WEIGHTS["tool_pct"]                # 0-15 pts
    score += min(vectors_ruled_out * SCORE_WEIGHTS["vectors"], 10)  # cap at 10
    score += min(forge_tests * SCORE_WEIGHTS["forge_tests"], 10)    # cap at 10

    # Git commit
    commit = _git_short_hash()

    return ExperimentResult(
        run_id=manifest.get("run_id", "unknown"),
        commit=commit,
        audit_score=round(score, 1),
        regression=f"{regression_found}/{regression_total}",
        findings=confirmed_findings,
        tool_pct=tool_pct,
        vectors=vectors_ruled_out,
        forge_tests=forge_tests,
        wall_time_s=wall_time_s,
        status="pending",  # caller sets to keep/discard
        description="",    # caller sets
    )


def _check_regression(wave_number: int) -> tuple[int, int]:
    """Re-run regression check against cumulative sidecars."""
    from .regression import check_regression
    from .run_audit import _collect_cumulative_sidecars
    cases_path = Path(__file__).parent / "regression_cases.json"
    if not cases_path.exists():
        return 0, 0
    sidecars = _collect_cumulative_sidecars(wave_number)
    result = check_regression(sidecars, cases_path)
    return len(result.get("found", [])), result.get("total", 4)


def _compute_tool_compliance(warnings: list[str], agent_count: int) -> int:
    """Compute tool compliance percentage from tool coverage warnings.

    4 mandatory tools per agent (audit_context_building, entry_point_analyzer,
    slither, aderyn). Each missing tool = one warning containing "did NOT run".
    """
    mandatory_per_agent = 4
    total_mandatory = mandatory_per_agent * agent_count
    missing = sum(1 for w in warnings if "did NOT run" in w)
    if total_mandatory == 0:
        return 100
    ran = total_mandatory - missing
    return max(0, min(100, int(100 * ran / total_mandatory)))


def _count_forge_tests(wave_number: int) -> int:
    """Count ruled-out vectors that have Forge test evidence."""
    from .synthesizer import collect_json_sidecars
    from .config import WAVES
    wave = WAVES[wave_number - 1]
    sidecars = collect_json_sidecars(wave)
    count = 0
    for sc in sidecars:
        for ro in sc.get("ruled_out_vectors", []):
            test_file = ro.get("test_file", "")
            if test_file and test_file not in ("null", "N/A", "None", ""):
                count += 1
    return count


def _git_short_hash() -> str:
    """Get current git short hash."""
    try:
        result = subprocess.run(
            ["git", "rev-parse", "--short", "HEAD"],
            capture_output=True, text=True, timeout=5,
        )
        return result.stdout.strip() or "unknown"
    except Exception:
        return "unknown"


# --- TSV Logger ---

EXPERIMENTS_TSV = Path(__file__).parent.parent / "targets" / "full-system" / "experiments.tsv"
TSV_HEADER = "run_id\tcommit\taudit_score\tregression\tfindings\ttool_pct\tvectors\tforge_tests\twall_time_s\tstatus\tdescription\n"


def log_experiment(result: ExperimentResult) -> None:
    """Append an experiment result to experiments.tsv."""
    if not EXPERIMENTS_TSV.exists():
        EXPERIMENTS_TSV.write_text(TSV_HEADER)

    row = (
        f"{result.run_id}\t{result.commit}\t{result.audit_score}\t"
        f"{result.regression}\t{result.findings}\t{result.tool_pct}\t"
        f"{result.vectors}\t{result.forge_tests}\t{result.wall_time_s}\t"
        f"{result.status}\t{result.description}\n"
    )
    with open(EXPERIMENTS_TSV, "a") as f:
        f.write(row)

    print(f"  Experiment logged: audit_score={result.audit_score} "
          f"regression={result.regression} tools={result.tool_pct}% "
          f"vectors={result.vectors} status={result.status}")


def read_experiments() -> list[ExperimentResult]:
    """Read all experiments from TSV."""
    if not EXPERIMENTS_TSV.exists():
        return []
    results = []
    with open(EXPERIMENTS_TSV) as f:
        reader = csv.DictReader(f, delimiter="\t")
        for row in reader:
            results.append(ExperimentResult(
                run_id=row["run_id"],
                commit=row["commit"],
                audit_score=float(row["audit_score"]),
                regression=row["regression"],
                findings=int(row["findings"]),
                tool_pct=int(row["tool_pct"]),
                vectors=int(row["vectors"]),
                forge_tests=int(row.get("forge_tests", "0")),
                wall_time_s=int(row.get("wall_time_s", "0")),
                status=row["status"],
                description=row["description"],
            ))
    return results


def best_score() -> float:
    """Return the best audit_score from all experiments."""
    experiments = read_experiments()
    if not experiments:
        return 0.0
    return max(e.audit_score for e in experiments)
```

## Experiment Loop

```
LOOP:
  1. DIAGNOSE: Read experiments.tsv + latest wave artifacts
     - What is the audit_score bottleneck? (regression? tools? findings?)
     - Read wave1-synthesis.md for tool coverage warnings
     - Read wave1-safety.jsonl for agent failures
     - Read agent findings.json metadata for what agents actually did
     - Check run stdout/stderr for crashes, SDK errors, MCP failures

  2. CLASSIFY the fix needed:
     - SYSTEM FIX: SDK wiring, MCP propagation, artifact collection,
       synthesis parsing, schema validation (agents can't succeed
       because infrastructure is broken)
     - PROMPT FIX: Agent instructions, checkpoint language, hypothesis
       specificity, tool enforcement (agents can succeed but don't
       because instructions are unclear)
     - CONFIG FIX: Agent count, scope, turn budget, thinking budget,
       model selection (agents do the right things but suboptimally)

  3. IMPLEMENT: Modify relevant files. System fixes first — there's no
     point optimizing prompts if MCP servers aren't propagated.

  4. git commit -m "experiment: {category}: {hypothesis}"

  5. RUN: python3 -m docs.orchestrator.run_audit --wave 1 --fresh \
         --experiment --description "{category}: {hypothesis}"

  6. EVALUATE: Check experiments.tsv
     - If audit_score improved → keep (advance)
     - If audit_score same/worse → discard (git reset --hard HEAD~1)

  7. GOTO 1
```

## Diagnostic Checklist (run BEFORE proposing changes)

When audit_score is stuck, systematically check each layer:

### Infrastructure (check first — broken pipes mean 0 signal)
- [ ] Do agents have MCP servers? Check `setting_sources` in wave_runner.py
- [ ] Do agents get tool permissions? Check `.claude/settings.local.json`
- [ ] Does synthesis parse sidecar data correctly? Check synthesis.md ruled-out section
- [ ] Is stop_reason accurate? Check metrics.json for false "missing"
- [ ] Do agents write artifacts to the right paths? Check artifact dirs after run

### Prompts (check second — unclear instructions mean wasted turns)
- [ ] Are mandatory checkpoints INLINE or referenced? Inline = followed, reference = skipped
- [ ] Do agents know HOW to invoke tools? Check tool commands in preamble
- [ ] Are hypotheses specific enough? (function names > abstract patterns)
- [ ] Is the sidecar schema clear? Do agents produce valid JSON?

### Config (check third — suboptimal settings mean diminishing returns)
- [ ] Is max_turns sufficient? Do agents hit the cap before finishing?
- [ ] Is thinking budget useful? Compare 128K vs 32K
- [ ] Are 6 archetypes better than 3? Check for duplicate coverage

## What to Try (ordered by expected impact)

### System fixes (highest expected impact when score = 0)
1. **MCP wiring**: Ensure slither/aderyn MCP servers propagate to agents
2. **Artifact collection**: Fix paths, parsing, validation
3. **Synthesis bugs**: Fix rendering, dedup, scoring
4. **SDK options**: setting_sources, permission_mode, thinking config

### Prompt fixes (medium impact)
5. **Regression seeding**: Add 4 known bug descriptions directly in templates
6. **Tool enforcement**: Inline checkpoint commands (not just references)
7. **Hypothesis specificity**: Exact function:line targets vs abstract patterns
8. **Pre-completion gate**: Checklist agents must verify before finishing

### Config tuning (lower impact, fine-tuning)
9. **Agent count**: 6 vs 3 broader agents
10. **Scope narrowing**: 2 repos vs all 6 per agent
11. **Turn budget**: 30 vs 200
12. **Thinking budget**: 128K vs 64K vs 32K

## Simplicity Criterion (from autoresearch)

All else being equal, simpler is better. A small audit_score improvement that
adds ugly complexity is not worth it. Removing code/prompt sections and getting
equal or better results is a simplification win.

## What's NOT in This Plan (Layer 3: Autonomous Loop)

The autonomous `run_experiment.py` that LOOPS FOREVER — proposing prompt changes, running experiments, and iterating — requires:

1. A meta-researcher agent prompt (like autoresearch's `program.md` but for an LLM that modifies other LLM prompts)
2. Validated scoring (Layer 1+2 must work first)
3. Clear keep/discard git branching (e.g., `git checkout -b experiment/mar14-run3`)

This is designed but deferred until Layer 1+2 prove the scoring is meaningful across 3-5 manual runs. Then we build the loop with confidence that the metric tracks actual audit quality.

**Usage after this plan:**
